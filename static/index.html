统计口径

分支与历史

默认包含所选分支可达的所有祖先提交。“所有分支”取本地分支、远程跟踪分支和 HEAD 的并集，每条提交只计一次，不包含仅由标签或 stash 引用的历史。不会切换分支或修改仓库。

新增、删除与累计净变更

基于 Git numstat 的文本行增删，包含文档、配置、依赖锁文件和仓库中提交过的生成文件。累计净变更 = 新增 − 删除，不等于当前代码总行数。二进制文件只记文件变更次数；重命名按删除旧文件和新增新文件处理。

合并提交与第一父链

默认保留合并提交的记录，但不累加其文件增删，避免把合入的历史重复计算。“只看第一父链”仅沿第一父提交回溯，并统计合并相对第一父提交的变化。所有分支模式使用完整历史。

时间与筛选

按 Git 作者日期统计，保留每条提交的原始时区。活动天数、连续天数基于这些日期；无法推算实际工作时长。近 30 / 90 天以今天为基准。顶部筛选与时间范围滑块同时作用于全部视图。点击日期或月份，在侧栏查看对应提交。

缓存与数据边界

缓存保存在应用的 .cache 目录，引用变化后会重新解析。浅克隆仅显示本地已有历史；未提交内容和已删除且不可达的提交不在统计中。点击刷新可强制重建当前视图缓存。

导出与快捷键

“导出回忆”可保存当前筛选的离线可视化 HTML 报告或完整提交 CSV。Ctrl / ⌘ K 聚焦搜索，Esc 关闭详情。提交列表支持上下方向键选择。时间滑块支持方向键调整，图表下方可回放历史。
