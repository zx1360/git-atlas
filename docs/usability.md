# 界面与交互更新 · 2026-11-08

保留本地只读的 Git 统计与缓存，重新组织浏览界面。

## 布局

- 顶栏集中仓库切换、总览 / 提交 / 节律三个视图，以及导出入口。
- 分支、仅主线、日期、作者与搜索合并为全局筛选栏；滚动时保持可见。
- 移除大标题、英文副标题、侧栏装饰、统计卡片的重复说明和常驻操作提示。
- 统计直接显示数值。筛选后提交数显示“匹配 / 全部”，活跃天数显示“活跃 / 所选范围总天数”。
- 时间范围使用全程预览与两个可拖动把手，能扩大或缩小范围；筛选控件自身显示选中状态。

## 操作范围

| 操作 | 结果 |
| --- | --- |
| 顶部筛选、图表拖动、时间把手 | 更新全部视图的筛选范围 |
| 点击日期或月份 | 在侧栏查看期间的提交，保留当前页面和全局范围 |
| 点击提交或历史节点 | 在同一侧栏显示详情，来源行保持选中 |
| 从期间列表进入提交，再返回 | 回到之前的期间列表与页码 |
| 关闭详情 | 回到原来的浏览位置；窄窗口恢复原焦点 |

桌面采用并排详情。窄窗口采用抽屉，限制焦点在抽屉中，并支持 Esc 关闭。日历缩窄时会保持选中日期在横向可见区域。

提交列表独立滚动，分页控件保持在列表外。支持直接输入页码和方向键查看相邻提交。重新打开时恢复上次的仓库与分支；浏览器后退可返回之前的视图。

快捷键：Ctrl / ⌘ K 聚焦全局搜索；Enter 查看匹配提交；提交列表上下方向键切换详情；日历方向键移动日期；时间把手方向键调整起止日期。

- 8 项真实 Git 集成测试保持通过；JavaScript 语法检查通过。
- 桌面并排详情：日期查看 → 提交详情 → 返回日期列表，全局统计与日期范围保持不变。
- 实际拖动时间把手；通过方向键缩小范围，再通过 Home 扩大回全部日期。

- 列表独立滚动、第三页跳转、方向键选择、空结果重置、浏览器后退与 Ctrl K。
